# RemotoFácil

Configura Tailscale, Sunshine y Moonlight para usar tu PC desde otro dispositivo.

- `linux/`: versión para Linux (.NET 8 y Avalonia). Se empaqueta con `construir-appimage.sh`.
- `windows/`: versión para Windows (.NET Framework 4.8 y Windows Forms).

## Créditos y agradecimientos

RemotoFácil existe gracias a estos proyectos. Muchas gracias a sus equipos y comunidades:

- **[Tailscale](https://tailscale.com)**: la red privada que conecta tus dispositivos.
- **[Sunshine](https://github.com/LizardByte/Sunshine)**, de LizardByte: el servidor que transmite tu PC.
- **[Moonlight](https://moonlight-stream.org)**: la aplicación con la que te conectas desde el otro dispositivo.

RemotoFácil no está afiliado a ninguno de ellos ni cuenta con su respaldo. Cada proyecto tiene su propia licencia y sus marcas pertenecen a sus dueños.
